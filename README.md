# Antonio Moreta — personal academic website

Abre index.html en el navegador para ver la web. Las tres páginas funcionan sin instalación ni servidor.

## Editar
- index.html: bio y enlaces.
- research.html: publicaciones y proyectos.
- teaching.html: docencia.
- style.css: diseño y adaptación al móvil.
- assets/cv.pdf: reemplazar para actualizar el CV.
- assets/antonio.jpg: fotografía.

## Publicar
La carpeta contiene una web estática compatible con GitHub Pages y otros alojamientos estáticos. Sube su contenido a la raíz del repositorio elegido y configura la publicación de esa carpeta. Una vez verificada la web publicada, conecta antoniomoreta.com desde el proveedor de alojamiento y configura los DNS que indique. El dominio no se ha modificado.

Sin dependencias externas, scripts, cookies ni servicios de seguimiento.
